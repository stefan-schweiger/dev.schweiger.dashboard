Screens
How screens work

Every browser showing the dashboard is a screen, so flow cards can highlight a widget or show a dashboard on one of them. Each name is used once; the short id (#3F9A) tells apart screens that were named alike before. This list is kept on your Homey, so it survives restarts and updates.

A browser can rename its screen or become another one in the dashboard's Settings. Disconnect there signs only that browser out: its screen stays here, and pairing again brings it back. Forget here removes a screen and breaks the flow cards aimed at it; a browser still showing it is disconnected and has to be approved again.

API key
…

The API key form in my.homey.app (Settings → API Keys) has no permission for dashboards, so a key made there only works with Homey ticked. That gives full access, and every paired browser holds the key.

Create a key with only the needed permissions

A tool that sets permissions directly, such as homeyctl, can make one:

homeyctl token create "Web Dashboard" --no-save --scopes homey.dashboard.readonly,homey.device.readonly,homey.device.control,homey.flow.readonly,homey.flow.start,homey.mood.readonly,homey.mood.set,homey.logic.readonly,homey.zone.readonly,homey.notifications.readonly,homey.app.readonly,homey.user.readonly,homey.user.self,homey.insights.readonly,homey.energy.readonly,homey.presence.self,homey.system.readonly,homey.geolocation.readonly

To change widgets on the web dashboards too (Edit, next to Settings), use homey.dashboard instead of homey.dashboard.readonly. Every paired browser can then also change and delete dashboards.

After saving, this page names anything missing or too broad. Paired browsers keep a copy of the key: to sign them all out, delete it and save a new one here.
