Paired before? Pick the screen this browser was, and flow cards aimed at it reach it again.

Use the HTTPS *.homey.homeylocal.com address so the browser allows the connection.

Create one in my.homey.app under Settings → API Keys. It is stored only in this browser.

This browser can't keep a screen id (a private window, say), so it only shows flow cards aimed at all screens.

Shrinks the dashboard until all its columns fit, instead of scrolling sideways.

For a wall tablet: hides the dashboard menu and Settings. After two minutes without a touch it closes open controls and comes back to this dashboard. To change it later, press and hold the dashboard name and approve the code in the Homey app.

It also asks the browser to keep the screen on, which browsers only allow over https, and Safari only after a tap. On an iPad, setting Auto-Lock to Never (Settings → Display & Brightness) is the reliable way.

Disconnect removes the key from this browser. The screen stays in the Homey app with its flow cards: pair again and it comes back as this screen. To remove a screen for good, forget it in the Homey app.
