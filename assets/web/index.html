This screen

This browser can't keep a screen id (a private window, say), so it only shows flow cards aimed at all screens.

Display

Shrinks the columns to fit instead of scrolling sideways.

Kiosk

For a wall tablet: hides the menu and Settings, and comes back to this dashboard after two minutes without a touch. To change it later, press and hold the dashboard name and approve the code in the Homey app.

Keeping the screen on

Kiosk mode asks the browser to keep the screen on, which browsers only allow over https, and Safari only after a tap. On an iPad, setting Auto-Lock to Never (Settings → Display & Brightness) is the reliable way.
